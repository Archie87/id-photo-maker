# 测试与验收

## 自动检查

- `pnpm typecheck`：核心包、Web 和 Worker 严格类型检查。
- `pnpm test`：毫米像素换算、眼线水平/位置、头高、无效关键点、非官方规格提醒、排版边界、PDF MediaBox、JPG/PNG DPI。
- `pnpm build`：生产静态导出与同源推理资产准备。
- `pnpm test:e2e`：导入、切换规格、四种文件下载、清除、手机布局；记录请求，检查没有外部请求或照片 POST。
- `pnpm fixture:download && pnpm test:e2e`：额外运行公开人像的真实模型推理测试。没有测试图时该项明确跳过。

## 人工验收矩阵（待真机测试）

Mac Safari/Chrome、Windows Chrome/Edge、iPhone Safari、iPad Safari。逐一检查：带 EXIF 旋转的照片、HEIC、12/24MP、大图内存、零人/多人、长发/卷发/眼镜、深色衣物、复杂背景、Worker 失败、快速换图、反复背景切换、照片清除。

导出验证包括实际像素、DPI、KB 上限是否满足、透明 Alpha、色彩偏移、照片是否完整。打印分别测试 A4 和 6 寸纸，实际大小 100%，用尺子检查 25×35 mm；打印机驱动的缩放/无边距选项可能改变结果，软件测试不能替代测量。

不得使用“合规通过”代替受理机构验收。头顶为外推、头高/眼高为通用参考、表情/睁眼/肤色/发丝质量需要人工检查。

## P1 构图与排版回归

单元测试涵盖 ROI 边界、像素行复制、原图只读、点顺序/边界、最终头高/眼高、标尺留白、裁切开关不改变布局。解压实际 PDF 内容流，核对两根标尺各为 50 mm 对应的 pt 长度。

浏览器测试覆盖公开人像的头肩/全图两种分割、透明 Alpha；点击/拖动的坐标回映射、数字微调、无效点禁用保存、应用与取消；6 寸/A4 预览、开关、实际 JPG 的 1800×1200/300 DPI、PDF 页面尺寸和手机对话框。真实打印验收仍待完成。
