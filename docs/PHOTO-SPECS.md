source 与 lastVerified 已写入各预设，status 仍为 preset；核对的是开源项目配置，不是办证机构完整规范。界面链接统一称为「规格来源」，不把 GitHub 标为官方办证依据。自定义尺寸不继承 Hivision 来源或核验日期。

居民身份证电子照仍以原公安来源保留 358×441 px、350 DPI、白底 JPG；Hivision 表中同像素条目名为「社保卡」，不能视为同一用途。其余考试、签证、社保等条目完整保留上游像素和名称；同尺寸不同用途不合并为一个按钮。本次同步尺寸表及现有底色；头高、眼高及自动构图算法仍为项目既有四点几何模型，不宣称与 Hivision 构图一致。

35×53 mm 二寸在 6 寸相纸上旋转排 2×2 共四张，单张不缩小，整体照片区 108×72 mm，间隔 2 mm。打印按实际大小 100% 输出，首次测量成品 35×53 mm。

新增像素条目使用显式 pixelSize；毫米字段仅作参考，禁止用于 PDF 或相纸排版。五寸严格保留上游 1050×1499，未改为 1050×1500 或据此反推并宣称 127 mm 打印高度。需要打印请选择明确毫米规格；上游仅给像素的这些新增条目暂不提供排版。

Hivision CSV 本身没有逐项 DPI、底色、文件格式、KB 范围和当前机构要求。新增条目采用项目默认 300 DPI，允许 JPG/PNG、自定义背景与用户填写 KB 上限，不添加虚构的机构约束；只有单独的居民身份证预设强制白底 JPG/350 DPI。接口使用 restrictBackground 单独控制背景限制，不再将所有固定像素预设视为身份证要求。

规格列表支持名称或尺寸搜索，搜索无结果保留当前编辑内容；列表独立滚动，避免 19 个条目撑开整个工作台。data/hivision-size-list.csv 保存固定提交的原始中文表用于完整性回归，来源、许可见 THIRD_PARTY_NOTICES.md。
