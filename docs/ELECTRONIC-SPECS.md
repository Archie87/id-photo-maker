# 居民身份证电子照基础预设

2026-10-02 根据用户要求加入；独立于普通一寸照片。

| 字段        | 值                                          |
| ----------- | ------------------------------------------- |
| ID          | cn-resident-id-electronic                   |
| 像素宽 × 高 | 358 × 441                                   |
| DPI 元数据  | 350                                         |
| 格式        | JPG / JPEG                                  |
| 背景        | 白色                                        |
| 毫米参考值  | 26 × 32；不用于此电子预设的排版             |
| KB 范围     | 按受理机构要求填写上限；未设统一最小/最大值 |

来源：[南昌市公安局公开采集参数](https://ncga.nc.gov.cn/ncgaj/zfcg/202512/2adc274baea14b8ba4fb03dcb4723cce.shtml)，核对日期 2026-10-02。该页面列明 358（宽）×441（高）、350dpi、24 位 RGB、JPEG，并有白色背景处理要求。页面列出的文件大小和上传限制属于具体采集系统，本预设不将其推广到所有社保、报名或身份证受理渠道。

实现边界：`pixelSize` 是电子文件尺寸的唯一依据，DPI 或毫米参考值变化不能改变固定像素；预览、构图、输出验证和导出使用同一 `outputSize` 函数。JPG 写入 JFIF 英寸单位及双轴 350 DPI。此预设只提供单张 JPG，打印请选择明确的毫米规格。切换预设不重新运行 AI，保留已缓存的人像。

`source` 与 `lastVerified` 记录此次基础参数核对，`status` 仍为 `preset`。`verificationNote` 提示未完整实现 GA/T 461 的制证质量要求。头高/眼高仍是通用构图参考，脸宽、具体头顶留白、姿态、表情、背景均匀度、颜色与压缩品质等完整约束尚未自动检查。没有 AI 分割时，选择白底也不会覆盖原始不透明背景。以上情况均不能解释为“已合规”。
