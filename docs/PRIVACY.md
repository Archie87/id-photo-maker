# 隐私与数据流

选择的照片通过 File API 读取，在浏览器内存解码、推理、渲染和导出。没有上传接口、用户账户、遥测或第三方字体请求。Worker 与模型从部署站点同源加载。模型下载脚本只下载公开模型，不处理用户照片。

清除照片/重新选择/离开页面会取消任务并丢弃应用对照片的引用；内存回收由浏览器控制，不声称安全擦除。下载的文件由用户管理。没有使用 LocalStorage、IndexedDB 或数据库保存照片。

导出不复制原始 EXIF/GPS 字段；浏览器编码行为和色彩转换仍应在目标浏览器上验证。JPEG 重新编码会损失信息，原始文件不修改。

静态托管服务器可能有普通 HTTP 访问日志，但不接收照片内容。未来服务器 Provider 必须新增明确上传选择、服务地址、保留期限和取消行为，不能作为静默降级。个人照片不得进入测试仓库或 CI。
