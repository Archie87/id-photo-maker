# V1 产品需求

## 定位

个人使用、家庭打印和轻量自部署的本地证件照工具。正式名称 ID Photo Maker；原对话中的 IDPhoto Studio 为早期工作名。主路径：选择照片 → 本地检测/分割 → 构图/背景 → 检查 → 单张/排版导出。

## 决策

采用浏览器本地优先，预留 Python 服务器 Provider。V1 初始版本不运行服务器 AI、不自动上传。参考上游架构并独立实现，不直接 Fork。Mac 上开发；静态站点可以部署到 PVE/NAS，无需为静态托管准备 GPU。

## 功能与验收

| 功能     | 目标                           | 当前基础版                                                      |
| -------- | ------------------------------ | --------------------------------------------------------------- |
| 导入     | JPG / PNG / HEIC、方向归一化   | JPG/PNG/WebP；HEIC 取决于浏览器                                 |
| 人脸     | 单人检测、眼睛/下巴/头顶       | MediaPipe 眼睛/下巴；头顶外推并提示人工确认                     |
| 自动构图 | 眼线水平、头高/眼高、居中      | 仿射变换 + 手动位置/缩放/旋转                                   |
| 去背景   | 人像与发丝保留                 | Selfie Segmenter 基础分割；精细抠图待后续                       |
| 背景     | 白/蓝/红/自定义/透明           | 已接入；颜色变化不重跑模型                                      |
| 美化     | 亮度、对比度、肤色、轻磨皮     | 亮度/对比度；其余延期                                           |
| 规格     | 常用尺寸、自定义、可扩展机构库 | 四种通用预设、358×441 身份证电子照基础预设与 10–100 mm 自定义   |
| 检查     | 格式、尺寸、KB、头高、眼高等   | 几何参考/导出编码校验；不声称官方合规                           |
| 导出     | JPG、透明 PNG、300 DPI         | 已接入；透明 PNG 必须先去背景                                   |
| 打印     | 6 寸/A4、预览、PDF/图片        | 按 mm 排版，6 mm 外边距、2 mm 间隔；可选裁切线与横纵 50 mm 标尺 |
| 隐私     | 不上传、原图不修改             | 浏览器内存处理，不保存个人照片                                  |

## 非目标与后续

本轮不做账户、支付、云相册、官方受理保证、服装生成。V2 才考虑换正装、发型/闭眼修复、高清修复；这些必须有明确的真实性和用途说明。

## 资源预算

开发环境 Node 22.13+、pnpm 11、Git、现代浏览器。工作图最长边 2400 px，上传限制 30 MB；这并不消除浏览器初始解码大图的内存峰值。应在 iPhone Safari、iPad、Windows Edge/Chrome 和 Mac Safari 实测。当前代码不承诺所有设备可用。
